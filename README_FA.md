# اسکریپت یدک‌کش ESX

سیستم یدک‌کشی واقع‌گرایانه با طناب برای FiveM (فریم‌ورک ESX). خودروها را با طناب فیزیکی به هم وصل کنید، بکسل کنید، و اگر زیاده‌روی کنید سپرها واقعاً کنده می‌شوند و روی زمین می‌افتند.

## ویژگی‌ها

- **یدک‌کشی داخل خودرو** — خودروی هدف را انتخاب کنید، سپس از یدک‌کش به آن وصل شوید.
- **اتصال دستی پیاده** — دو خودرو را بدون سوار شدن به آن‌ها به هم لینک کنید (مناسب خودروهای قفل). سپر جلو/عقب به‌صورت خودکار بر اساس محل ایستادن شما تشخیص داده می‌شود.
- **نقاط اتصال داینامیک** — با `GetModelDimensions` طناب دقیقاً به مرکز سپرها وصل می‌شود، نه استخوان‌های عمومی `boot` و `engine`.
- **فیزیک واقع‌گرایانه پاره شدن طناب** — طناب در این موارد پاره می‌شود:
  - خودروی یدک‌شده از یدک‌کش جلو بزند (جهت اشتباه)
  - فاصله از حد مجاز بیشتر شود (`maxDistance + 3.0`)
  - یدک‌کش ۲۰ ثانیه گاز بدهد ولی حرکت نکند (گیر کردن)
- **خسارت مکانیکی** — هنگام پاره شدن طناب، سپر جلوی خودروی هدف کنده شده و روی زمین می‌افتد. اگر قبلاً کنده شده باشد، سپر عقب یدک‌کش می‌افتد.

## دستورات و نحوه استفاده

### یدک‌کشی داخل خودرو

۱. داخل خودرویی که قرار است یدک شود بنشینید و اجرا کنید:
   ```
   /towin start
   ```
۲. سوار یدک‌کش شوید (عقب یدک‌کش رو به خودروی هدف) و اجرا کنید:
   ```
   /towin add
   ```
   طناب وصل می‌شود: سپر عقب یدک‌کش ← سپر جلوی خودروی هدف.
۳. برای جدا کردن بدون خسارت:
   ```
   /towin end
   ```

### اتصال پیاده (link)

بدون نیاز به سوار شدن — مناسب خودروهای قفل.

۱. کنار **سپر جلو یا عقب** خودروی اول بایستید و اجرا کنید:
   ```
   /towin link
   ```
   > خودروی اول لینک شد. به خودروی دوم بروید و دوباره /towin link را بزنید.
۲. به خودروی دوم بروید، کنار سپر موردنظر بایستید و اجرا کنید:
   ```
   /towin link
   ```
   طناب سپر به سپر وصل می‌شود. لینک در انتظار پس از موفقیت خودکار پاک می‌شود.
۳. برای لغو لینک در انتظار (به‌صورت پیاده):
   ```
   /towin end
   ```

## تنظیمات

```lua
local maxDistance = 12.0       -- طول طناب قبل از بررسی پاره شدن (با ۳ متر تلرانس)
local stuckThreshold = 20000   -- میلی‌ثانیه گاز بدون حرکت قبل از پاره شدن
```
